# Portafolio Frontend Trainee 💻

Hola, soy **Mateo** 👋, estudiante y trainee de desarrollo frontend. En este repositorio reúno los proyectos de práctica que voy haciendo mientras aprendo: páginas con HTML, CSS y JavaScript, y mis primeros pasos con React y TypeScript.

## 🗂️ Proyectos

| Proyecto | Tecnologías | Descripción |
|---|---|---|
| [LOGIN-HTML-CSS](LOGIN-HTML-CSS) | HTML, CSS | Formulario de inicio de sesión. |
| [DEVSTUDY](DEVSTUDY) | HTML, CSS, JavaScript | Landing page de una plataforma de cursos con Flexbox, Grid y diseño responsive. |
| [LISTA-TAREAS-JS](LISTA-TAREAS-JS) | HTML, CSS, JavaScript | Lista de tareas para agregar, completar y eliminar tareas, que se guardan en `localStorage`. |
| [GASTOS-REACT-TS](GASTOS-REACT-TS) | React, TypeScript, Vite | Control de gastos con componentes, `useState`, props tipadas y total calculado. |

## ▶️ Cómo ejecutar

Los proyectos de HTML, CSS y JavaScript se abren directamente con el archivo `index.html` en el navegador.

Para el proyecto de React + TypeScript:

```bash
cd GASTOS-REACT-TS
npm install
npm run dev
```

## 🛠️ Habilidades practicadas

- **HTML:** estructura semántica, formularios y enlaces
- **CSS:** Flexbox, Grid, transiciones, gradientes y diseño responsive
- **JavaScript:** DOM, eventos, funciones, arrays (`filter`, `forEach`) y `localStorage`
- **React:** componentes, props, `useState`, renderizado condicional y listas con `map`
- **TypeScript:** tipos, interfaces y tipado de props
- **Git y GitHub:** control de versiones
